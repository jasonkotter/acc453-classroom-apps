# Barter Market

Runs on the shared classroom toolkit (`../_shared/`). Rules: [SPEC.md](SPEC.md). Running it in
class: [INSTRUCTOR_GUIDE.md](INSTRUCTOR_GUIDE.md).

- **Live:** students open `index.html`; the instructor opens `index.html?view=instructor`. Needs
  `_shared/schema.sql` installed in Supabase (trades use its `cls_trade` function).
- **Local demo:** add `?demo=1`. The instructor screen can add simulated students; each browser
  tab on the Student phone screen is one more student.
