# ACC 453 classroom apps

Static classroom games for ACC 453 Money and Banking, served by GitHub Pages.
Live multiplayer uses Supabase (backend in `_shared/schema.sql`); `_shared/config.js` (and Bank Run's own `config.js`) holds the project URL and its
publishable key, which is meant to be public. Only display names are stored.

The source of truth is a private course repository; this repository is a published copy.
